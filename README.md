# G-Tech - (Tech Generation) - Sistema de Assinatura De Planos

Bem-vindo ao repositório da **G-Tech**!


## 📌 Descrição

A Gtech é um sistema web desenvolvido em PHP para gerenciamento de planos, usuários e assinaturas.

A Gtech permite que clientes visualizem e assinem planos, enquanto administradores podem gerenciar usuários, planos e o funcionamento geral da aplicação.

---

## ⚙️ Funcionalidades

- ✅ Cadastro e login de usuários
- ✅ Controle de acesso (Admin e Usuário)
- ✅ CRUD de planos
- ✅ Sistema de assinaturas
- ✅ Dashboard administrativo
- ✅ Interface responsiva com Bootstrap

---

## 🛠 Tecnologias Utilizadas

- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap
- JavaScript

---

##  Estrutura do Projeto
/admin       → área administrativa
/user        → área do usuário
/includes    → configurações e templates
/assets      → arquivos estáticos (CSS, JS)
/public      → páginas públicas

## Instalação

1. Clone este repositório:
   ```bash
git clone https://github.com/gabriel97biell/Project-5-Semestre-PHP.git

2. Acesse o diretório do projeto:
    ```bash
    Project-5-Semestre-PHP
    ---
3. Configure o banco de dados:
    - Crie um banco de dados MySQL
    - Importe as tabelas/estrutura (use o arquivo .SQL para as tabelas)

4. Configure as variáveis de ambiente (como conexão com banco de dados) no arquivo de configuração do projeto.

6. Inicie o servidor local:
   ``` bash
    php -S localhost:8000
    ---
7. Acesse via navegador:
    ---
    http://localhost/gtech
    ---
